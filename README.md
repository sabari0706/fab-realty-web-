# Fab Realty website (static)

Deploy:
1. Install Node.js (nodejs.org), then open a terminal in this folder.
2. Run: npx vercel --prod
3. Log in when asked, accept the defaults, and Vercel prints your live URL.

Editing listings: change data/listings.json (put new photos/brochures in assets/
and reference them as /assets/<file-name>), then run `npx vercel --prod` again.
